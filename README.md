
# Conveyor System

## Github Link 
https://github.com/stvnhu/conveyor-system


## Description
My conveyor system consists of a flat ground with camera movement.

Use keyboard buttons to place objects such as conveyors and item spawners.

Conveyers will snap together with other conveyers in a straight line.

Item spawners will snap on top of the normal and short conveyers.

When an object is selected for placing, a green hitbox will highlight how much space the conveyer takes.

The hitbox will turn red when too close to the hitbox of another object.

A green hitbox will allow the object to be placed while a red hitbox will not.

When no object is selected for placing, left clicking on an object you have previously placed will select it highlighting it in a yellow box.

When a placed object is selected you may delete it by pressing x or reverse the movement direction of the selected conveyer by pressing f.

f will also work when an object is selected for placing before it is placed.

You can rotate a selected object before it is placed by pressing r.

g will reverse the movement direction of all placed conveyors.

## Controls
- WASD - Move Camera 
- Right Click drag - Rotate Camera

###
- Left Click - Place selected object / Select placed object
- 1 - Select Conveyor to place
- 2 - Select Conveyor Short to place
- 3 - Select Conveyor Inclined to place
- 4 - Select Box spawner to place
- 5 - Select Can spawner to place

###
- R - Rotate Object while placing
- F - Flip direction of selected conveyor
- G - Flip direction of all conveyors
- X - Delete selected object
